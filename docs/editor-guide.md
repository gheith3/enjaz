# دليل المحرّر — لوحة تحكم «إنجازات»

لوحة التحكم: `https://injazat.om/admin`. كل ما يظهر في الموقع يُعدَّل من هنا؛ لا توجد صفحات ثابتة.
الحفظ يحدّث الموقع فورًا (تُمسح ذاكرة الصفحات تلقائيًا).

## القواعد العامة

- **منشور / مسودة:** كل محتوى له مفتاح «منشور». المسودة تظهر في اللوحة فقط. «موعد النشر» يؤجّل الظهور إلى تاريخ لاحق.
- **النشر بالجملة:** في أي قائمة حدّد السجلات ثم «إجراءات» ← «نشر» أو «إلغاء النشر».
- **الحذف:** يُنقل إلى المهملات ويمكن استرجاعه (فلتر «المحذوفات» ← «استرجاع»).
- **عرض في الموقع:** زر «عرض» بجانب السجل المنشور يفتح صفحته.
- **اللغة:** كل نص له حقل عربي وحقل English. الموقع عربي الآن؛ الإنجليزية تُفعَّل لاحقًا وتستخدم ما يُكتب في حقول English.
- **الصور:** لكل صورة «وصف الصورة» (لقارئات الشاشة) و«نقطة التركيز» مثل `50% 20%` (أفقي ثم عمودي) لتحديد الجزء الذي يبقى
  ظاهرًا حين يقصّ التصميم الصورة. الصور المفرّغة (PNG بخلفية شفافة) تبقى شفافة، والموقع يعرض نسخة WebP خفيفة منها تلقائيًا.

## أين أجد ماذا؟

| في الموقع | في اللوحة |
|---|---|
| الإنجازات وصفحة كل إنجاز | المحتوى ← الإنجازات |
| المنجزون وصفحة كل منجز، «منجز/منجزة الأسبوع»، «ملهمون» | المحتوى ← المنجزون (تبويب «الظهور في الموقع») |
| المؤسسات والجامعات والاتحادات وأخبارها | المحتوى ← المؤسسات، الأخبار |
| الجوائز ودوراتها وفائزوها | المحتوى ← الجوائز |
| المختبر (الابتكارات والمنشورات العلمية) | المحتوى ← المختبر |
| صفحة الأخبار (`/news`) | المحتوى ← الأخبار (حقل «قسم الأخبار»)، التصنيفات ← أقسام الأخبار |
| المقالات، الكتّاب، الأعداد | المجلة |
| رسائل نموذج «تواصل معنا» | المحتوى ← رسائل التواصل |
| نصوص كل صفحة، أقسامها وترتيبها | الصفحات والقوائم ← صفحات الموقع |
| كلمات القيادة (سلايدر الرئيسية) | الصفحات والقوائم ← كلمات القيادة |
| القائمة والتذييل | الصفحات والقوائم ← القوائم |
| الشعار، الهاتف، البريد | الإعدادات ← هوية الموقع والتواصل |
| حسابات التواصل الاجتماعي (التذييل) | الإعدادات ← حسابات التواصل |
| العنوان والوصف الافتراضي عند المشاركة | الإعدادات ← محركات البحث والمشاركة |
| تحويل الروابط القديمة | الصفحات والقوائم ← تحويلات الروابط |

## الصفحة الرئيسية

صفحات الموقع ← «الرئيسية» ← «أقسام الصفحة»: اسحب لترتيب الأقسام، وأطفئ ما لا تريد. زر «النصوص والعناصر» يفتح نصوص القسم،
وللأقسام المختارة يدويًا قائمة «عناصر القسم».

| القسم | ما الذي يظهر فيه |
|---|---|
| السلايدر | «كلمات القيادة» الظاهرة، بترتيبها |
| شريط المنجزين | المنجزون المفعّل لهم «في شريط المنجزين بالرئيسية» |
| الأرقام | الأرقام المكتوبة في القسم، أو تُحسب من الموقع إن تُركت فارغة |
| أحدث الإنجازات | الإنجازات المفعّل لها «في أحدث الإنجازات» مع «المكان» (كبير / بطاقة / سطر) و«العنوان المختصر» |
| وجوه من عُمان | عنصر القسم الأول (صورة PNG مفرّغة، نص، رابط) |
| الجوائز | الجوائز التي لها «شكل بطاقة»، والبطاقة العريضة من عناصر القسم |
| ملهمون من عُمان | أول ٤ منجزين مفعّل لهم «ملهمون» (الغلاف المربع) |
| المقالات | المقالات المفعّل لها «في الصفحة الرئيسية»، وإلا الأحدث |
| الرياضة / الثقافة | عناصر القسم (الصورة، والوصف = الرياضة أو الشارة) |
| القسم العلمي | الأخبار المفعّل لها «في الصفحة الرئيسية» + أحدث ٣ ابتكارات من المختبر |
| إنجازات المؤسسات | المؤسسات المفعّل لها «شريك»، صفًا لكل نوع |

## الصفحات الأخرى

- **ملهمون من عُمان:** المنجزون المفعّل لهم «ملهمون» مع المجال والعبارة وثلاث صور (لوح طولي، صورة شخصية، غلاف مربع).
  «هِمَمٌ بلا حدود» قسم في الصفحة؛ عناصره (أولها الكبير) + الأخبار المفعّل لها «همم بلا حدود».
- **من نحن:** النصوص الثابتة في «نصوص التصميم»، وكل قائمة (المجالات، خارطة العمل، كلمة المؤسس، الشهادات، الفريق،
  إنجازاتنا، المكتبة الإعلامية) قسم له عناصره. ترتيب أقسام هذه الصفحة ثابت؛ إطفاء قسم يخفيه.
- **تواصل معنا:** البريد والأرقام والمقر في «نصوص التصميم»؛ مواضيع النموذج في التصنيفات ← مواضيع التواصل.
  الرسائل تصل إلى «رسائل التواصل» (العدد غير المقروء بجانب الاسم) وتُرسل إلى البريد المكتوب في الصفحة.
- **المقالات:** أحدث عدد منشور يظهر في رأس الصفحة مع «مقال العدد» واقتباسه. مدة القراءة تُحسب من النص. «الأكثر قراءة»
  من عدد القراءات الفعلي. داخل النص: الاقتباس البارز يُوضع بعد أول فقرة من القسم الأول، والخلاصة قبل العنوان الثاني.
- **المختبر:** «اختراع / ابتكار» أو «منشور علمي»؛ «المعرض» هو اسم زر الفرز (العناصر بنفس الاسم تجتمع تحته).

## صحة المحتوى

الصفحة الأولى في اللوحة تعرض الأعداد (منشور / مسودة) و«صحة المحتوى»: سجلات منشورة بلا صورتها الرئيسية، ومسودات تنتظر.
ما استُورد من التصميم وعليه «تجريبي» (أخبار، مقالات، كتّاب، أخبار المؤسسات) مسودات حتى تستبدله بمحتوى حقيقي.

## الصلاحيات

- **مدير النظام (super_admin):** كل شيء.
- **مدير (admin):** كل شيء عدا المستخدمين والأدوار.
- **محرّر (editor):** المحتوى والصفحات والقوائم؛ بلا المستخدمين والأدوار وسجل النشاط والتحويلات وحسابات التواصل والإعدادات.

كل مستخدم يغيّر اسمه وبريده وكلمة مروره من «الملف الشخصي» (اسمه أسفل القائمة الجانبية)؛ تغيير البريد أو كلمة المرور يطلب كلمة المرور الحالية.

المستخدمون من النظام ← المستخدمون.
